# Nodeseek 轻量 Windows 客户端

基于 **Tauri v2** 的极轻量 Nodeseek 论坛客户端，专为低内存设备设计（如小米平板2，2GB RAM）。

## ✨ 特性

- 🪶 **极低内存占用**：仅 ~50-100MB RAM（对比 Electron 的 200-400MB）
- 📦 **极小安装包**：MSI 安装包约 3-5MB
- 🚀 **快速启动**：用系统 WebView2 渲染，启动即用
- 🎮 **平板优化**：默认 1280x720 窗口，支持全屏

## 📥 获取安装包

在 Actions 页面运行 "构建 Nodeseek Windows 客户端" 工作流，下载构件。

## 🖥 最低配置

| 项目 | 要求 |
|------|------|
| 系统 | Windows 10/11 x64 |
| 内存 | 最小 1GB，推荐 2GB |

## ⌨️ 快捷键

- `F11` - 切换全屏
- `Alt+Left` - 后退
- `Alt+Right` - 前进
- `Ctrl+R` - 刷新
